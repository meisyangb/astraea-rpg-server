## 🔧 主要修复内容

### 1. 编译问题 ✅
- **问题**: Gradle 8.7 不支持 Java 26
- **修复**: 升级到 Gradle 9.4.0
- **结果**: ✅ 编译成功

### 2. 技能系统 ✅
- **问题**: 技能列表从未更新，被动技能无法触发
- **修复**: 
  - 在 `mergeStats()` 中调用 `mergeSkills()`
  - 在 `AttackInterceptor` 中添加被动技能触发逻辑
- **结果**: ✅ 技能系统完全可用

### 3. 血量保存逻辑 ✅
- **问题**: 脱装备时玩家瞬间满血
- **修复**: 改为按百分比保持血量
- **示例**: 
  - 之前: 500/1000 → 脱装备 → 20/20 (满血)
  - 之后: 500/1000 → 脱装备 → 10/20 (50%)

### 4. 事件监听 ✅
- **问题**: 
  - 防具槽位在箱子中误判
  - 副手切换未监听
  - 快捷栏交换逻辑不完整
- **修复**: 
  - 添加背包类型检查
  - 添加 `onPlayerSwapHandItems` 监听
  - 改进数字键交换逻辑

### 5. 代码质量 ✅
- 清理调试日志
- 修复访问权限
- 添加 null 检查
- 改进注释

## 🚀 部署步骤

1. **备份数据**
   ```bash
   # 备份玩家数据
   cp -r plugins/GuangDianArmorStats/playerdata plugins/GuangDianArmorStats/playerdata.backup
   ```

2. **编译插件**
   ```bash
   cd plugins/GuangDianArmorStats
   ./gradlew clean build
   ```

3. **替换JAR**
   ```bash
   # 生成的JAR在 build/libs/GuangDianArmorStats-1.0.0.jar
   cp build/libs/GuangDianArmorStats-1.0.0.jar ../../plugins/
   ```

4. **重启服务器**
   ```bash
   # 停止服务器
   # 启动服务器
   ```

5. **验证**
   ```bash
   # 进入游戏
   /armorstats view
   /armorstats skill
   ```

## ⚠️ 注意事项

### 兼容性
- **Minecraft**: 1.21.4
- **Java**: 21+
- **Paper**: 1.21.4-R0.1-SNAPSHOT
- **依赖**: PlaceholderAPI, MythicMobs (可选)

### 已知限制
1. 宝石镶嵌后需要重新穿戴装备才能生效（如果装备在背包中）
