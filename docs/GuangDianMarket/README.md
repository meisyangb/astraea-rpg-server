# GuangDianMarket

> 光点全球市场 — 玩家物品上架/购买/搜索/分类筛选，支持双货币(点券+金币)

---

## 一、简介

GuangDianMarket 提供全球拍卖行式物品交易市场，支持玩家上架物品、搜索、分类筛选，双货币(点券+金币)支持。

### 功能特性

- **分类筛选** — 武器/防具/工具/材料/食物/药水/附魔/其他
- **双货币** — 点券(GD Points) + 金币(Vault)
- **搜索功能** — 聊天框搜索物品名
- **离线返还** — 过期未售物品自动返还

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/market` | `guangdian.market.use` | 打开全球市场 |
| `/market sell <价格> [货币]` | `guangdian.market.use` | 上架手中物品(points/coins) |
| `/market my` | `guangdian.market.use` | 查看我的上架 |
| `/market search <关键词>` | `guangdian.market.use` | 搜索物品 |
| `/market help` | 无 | 帮助 |
