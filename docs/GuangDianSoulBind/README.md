# GuangDianSoulBind

> 光点灵魂绑定 — 物品绑定/防掉落/绑定石/解绑

---

## 一、简介

GuangDianSoulBind 提供物品灵魂绑定功能，绑定后物品死亡不掉落、不可交易。

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/soulbind` | 无 | 绑定手中物品(消耗绑定石) |
| `/soulbind unbind` | 无 | 解绑物品 |
| `/soulbind info` | 无 | 查看绑定信息 |
| `/soulbindadmin give <玩家> <绑定石ID>` | `guangdian.soulbind.admin` | 给予绑定石 |
