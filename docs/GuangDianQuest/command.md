# GuangDianQuest 命令权限完整参考

## 权限节点

| 权限节点 | 说明 |
|---------|------|
| `guangdian.quest.admin` | 管理员权限(重载、重置每日、手动对话) |

## 命令详细说明

### `/quest` — 打开任务 GUI 主菜单

- **权限**: 无
- **说明**: 打开 Inventory GUI，显示任务主菜单(进行中/可接取/任务线/每日/支线)

### `/quest list` — 查看任务列表

- **权限**: 无
- **说明**: 聊天框显示所有进行中和可接取任务

### `/quest info <任务ID>` — 查看任务详情

- **权限**: 无
- **参数**: `任务ID` — 任务配置文件中的 ID
- **显示**: 任务名称、描述、目标进度(当前/需求)、奖励预览、状态

### `/quest accept <任务ID>` — 接取任务

- **权限**: 无
- **前置检查**:
  - 任务存在且未接取未完成
  - 满足前置任务要求
  - 活跃任务数未达上限(max-active-quests)
  - 玩家等级满足 required-level

### `/quest complete <任务ID>` — 提交完成任务

- **权限**: 无
- **条件**: 所有目标进度均达到 amount
- **效果**: 发放奖励、更新任务线进度、触发解锁通知

### `/quest abandon <任务ID>` — 放弃任务

- **权限**: 无
- **效果**: 从活跃列表移除，进度清零

### `/quest daily` — 每日任务

- **权限**: 无
- **说明**: 显示当日可接取的每日任务列表

### `/quest track` — 追踪进度

- **权限**: 无
- **说明**: 聊天框显示所有进行中任务的目标进度

### `/quest questline` — 任务线进度

- **权限**: 无
- **说明**: 显示所有任务线的当前进度索引

### `/quest reload` — 管理员重载

- **权限**: `guangdian.quest.admin`
- **说明**: 重载 quests 目录下所有任务文件、questlines.yml、config.yml

### `/quest resetdaily [玩家]` — 重置每日任务

- **权限**: `guangdian.quest.admin`
- **参数**: 可选玩家名(玩家使用重置自己，控制台需指定)

### `/quest talk <NPCID> [玩家]` — 手动触发 NPC 对话

- **权限**: `guangdian.quest.admin`(调试信息)
- **参数**: NPCID 必填、玩家名可选(控制台必填)
