# GuangDianSignIn

> 光点签到系统 — 每日签到/连续签到奖励/累计签到里程碑

---

## 一、简介

GuangDianSignIn 提供每日签到功能和连续签到奖励。

### 功能特性

- **每日签到** — 每日一次签到
- **连续签到** — 连续天数额外奖励
- **累计签到** — 总签到天数里程碑奖励
- **GUI 界面** — 签到日历展示

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/signin` | 无 | 每日签到 |
| `/signin info` | 无 | 签到信息 |
| `/signin reward` | 无 | 领取累计奖励 |
