# GuangDianSocket

> 光点宝石镶嵌系统 — 7孔镶嵌/拆卸/保险符，基于 PDC 存储宝石属性，40+属性支持

---

## 一、简介

GuangDianSocket 为 RPGItems 装备提供宝石镶嵌功能，支持最多7个宝石孔的镶嵌和拆卸，所有宝石数据通过 Minecraft PDC 持久化存储。

### 功能特性

- **7孔镶嵌** — 装备最多7个宝石孔
- **拆卸系统** — 消耗拆卸石/保险符取下宝石
- **PDC 存储** — 宝石数据存在装备 NBT 中
- **40+属性** — 攻击/防御/暴击/生命/魔力等全部属性类型
- **范围值** — 宝石属性支持固定值或随机范围

### 前置要求

| 插件 | 说明 | 必装 |
|------|------|:----:|
| RPGCore | 核心框架 | ✅ 是 |
| RPGItems | 装备系统 | ✅ 是 |
| GuangDianArmorStats | 属性系统 | ✅ 是 |

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/socket` | 无 | 打开镶嵌 GUI |
| `/socket gui` | 无 | 同上 |
| `/socket help` | 无 | 帮助信息 |
| `/socket reload` | `guangdiansocket.admin` | 重载配置 |

---

## 三、GUI 界面

镶嵌 GUI 为 27 格界面：
- 中心格: 装备槽(放入待镶嵌装备)
- 7个孔位: 放入宝石
- 确认/取消/拆卸按钮
