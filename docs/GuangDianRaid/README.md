# GuangDianRaid

> 光点突袭系统 — 定时怪物攻城/波次系统/Boss波/全服奖励

---

## 一、简介

GuangDianRaid 提供定时怪物攻城事件，支持多波次、Boss波和全服奖励。

---

## 二、命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/raid info` | 无 | 查看下次突袭时间 |
| `/raid start <ID>` | `guangdian.raid.admin` | 手动开始突袭 |
| `/raid stop` | `guangdian.raid.admin` | 停止突袭 |
| `/raid reload` | `guangdian.raid.admin` | 重载配置 |
