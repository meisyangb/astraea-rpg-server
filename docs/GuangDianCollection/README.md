# GuangDianCollection

> 光点收集系统 — 图鉴/收集进度/套装奖励/称号解锁

---

## 一、简介

GuangDianCollection 提供物品收集图鉴，玩家收集指定物品解锁进度奖励和称号。

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/collection` | 无 | 打开收集图鉴 |
| `/collection info` | 无 | 查看收集进度 |
| `/collection claim` | 无 | 领取收集奖励 |
