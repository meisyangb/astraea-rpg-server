# GuangDianMonthlyCard

> 光点月卡系统 — 购买/每日领取/自动续费/剩余天数

---

## 一、简介

GuangDianMonthlyCard 提供月卡购买和每日自动发放奖励系统。

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/monthlycard` | 无 | 查看月卡状态 |
| `/monthlycard buy` | 无 | 购买月卡 |
| `/monthlycard claim` | 无 | 领取今日奖励 |
| `/monthlycard info` | 无 | 查看详细信息 |
