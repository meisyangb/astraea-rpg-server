# GuangDianMarriage

> 光点结婚系统 — 求婚/接受/离婚/伴侣传送/称号/亲密度

---

## 一、简介

GuangDianMarriage 提供完整的伴侣系统，支持求婚、亲密关系管理、伴侣传送和称号系统。

### 功能特性

- **求婚系统** — 发起/接受/拒绝
- **离婚系统** — 双方解除关系
- **伴侣传送** — `/marry tp` 传送
- **称号系统** — 结婚后获得伴侣称号
- **亲密度** — 完成任务/击杀Boss获得

### 前置要求

| 插件 | 说明 | 必装 |
|------|------|:----:|
| RPGCore | 核心框架 | ✅ 是 |

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/marry propose <玩家>` | 无 | 求婚 |
| `/marry accept` | 无 | 接受求婚 |
| `/marry divorce` | 无 | 离婚 |
| `/marry tp` | 无 | 传送到伴侣 |
| `/marry info [玩家]` | 无 | 查看婚姻信息 |
| `/marry gift <玩家> <点数>` | 无 | 赠送点券 |
| `/marry help` | 无 | 帮助 |
