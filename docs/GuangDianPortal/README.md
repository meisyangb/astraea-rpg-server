# GuangDianPortal

> 光点传送门 — 自定义传送门/粒子入口/条件传送

---

## 一、简介

GuangDianPortal 创建自定义传送门，玩家走进粒子区域即可传送到目标位置。

---

## 二、命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/portal create <ID>` | `guangdian.portal.admin` | 创建传送门 |
| `/portal remove <ID>` | `guangdian.portal.admin` | 删除 |
| `/portal list` | `guangdian.portal.admin` | 列表 |
| `/portal reload` | `guangdian.portal.admin` | 重载 |
