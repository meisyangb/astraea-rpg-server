# GuangDianTrade

> 光点交易系统 — 玩家间安全交易/双方确认机制/防止诈骗

---

## 一、简介

GuangDianTrade 提供玩家间一对一安全交易功能，双方必须确认后交易才生效。

### 功能特性

- **安全交易** — 双方确认机制防止诈骗
- **多物品槽** — 支持多物品同时交易
- **点券交易** — 支持点券作为交易货币

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/trade <玩家>` | 无 | 发起交易请求 |
| `/trade accept` | 无 | 接受交易请求 |
| `/trade deny` | 无 | 拒绝交易请求 |
| `/trade help` | 无 | 帮助 |
