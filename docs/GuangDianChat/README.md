# GuangDianChat

> 光点聊天系统 — 频道切换/格式化/前缀称号/@提醒/禁言系统

---

## 一、简介

GuangDianChat 提供多频道聊天、自定义格式、称号前缀、@提醒和禁言管理。

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/chat global` | 无 | 切换到世界频道 |
| `/chat local` | 无 | 切换到附近频道 |
| `/chat guild` | 无 | 切换到公会频道 |
| `/chat party` | 无 | 切换到队伍频道 |
| `/mute <玩家>` | `guangdian.chat.admin` | 禁言玩家 |
| `/unmute <玩家>` | `guangdian.chat.admin` | 解除禁言 |
| `/chat reload` | `guangdian.chat.admin` | 重载配置 |

---

## 三、频道类型

| 频道 | 范围 | 说明 |
|------|------|------|
| global | 全服 | 默认频道 |
| local | 50格 | 附近玩家可见 |
| guild | 公会内 | 仅公会成员 |
| party | 队伍内 | 仅队伍成员 |
