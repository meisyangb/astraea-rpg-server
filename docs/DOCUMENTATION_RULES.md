# Astraea RPG 插件文档编写规范

> 本文档定义了 Astraea RPG 插件文档的编写规范和格式要求，所有文档贡献者必须遵循。

## 一、文档结构规范

### 1.1 文件命名

- 所有文档文件使用 **小写字母** 和 **连字符** 命名
- 文件扩展名必须为 `.md`
- 插件主文档必须命名为 `README.md`
- 子文档使用有意义的英文名称，例如：
  - `command.md` - 命令权限
  - `config.md` - 配置文件
  - `api.md` - API 接口
  - `examples.md` - 示例

**示例：**
```
GuangDianArmorStats/
├── README.md          # 插件主文档
├── command.md         # 命令权限
├── attributes.md      # 属性系统
├── config.md          # 配置文件
└── examples.md        # 使用示例
```

### 1.2 文档头部格式

每个文档必须以 YAML Front Matter 开头（可选），但必须包含标题和简介：

```markdown
# 插件名称

> 一句话描述插件的功能和用途

## 一、简介

（插件简介内容）
```

### 1.3 标题层级规范

- `#` - 文档标题（仅出现一次）
- `##` - 主要章节（一、二、三...）
- `###` - 子章节
- `####` - 更小节（如需要）

**注意：** 标题必须使用中文数字编号（一、二、三...）

## 二、内容格式规范

### 2.1 插件简介模板

每个插件文档的开头必须包含以下信息：

```markdown
# 插件名称

> 一句话描述

## 一、简介

（详细介绍）

### 特点

- **功能1** - 描述
- **功能2** - 描述

### 前置要求

- **必需**: 列出必需的依赖
- **可选**: 列出可选的依赖

### 兼容性

- **服务端**: Paper 1.21+
- **Java**: Java 21+
- **插件依赖**: 列出依赖的插件
```

### 2.2 命令文档格式

命令必须使用表格格式，并包含权限说明：

```markdown
## 二、命令权限

### 2.1 玩家命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/command` | 无 | 基础命令说明 |
| `/command <参数>` | `plugin.command` | 需要权限的命令 |

### 2.2 管理员命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/plugin reload` | `plugin.admin` | 重载配置 |
| `/plugin debug` | `plugin.admin.debug` | 调试模式 |
```

### 2.3 配置文件格式

配置文件必须使用 YAML 代码块，并添加详细注释：

```markdown
## 三、配置文件

### 3.1 config.yml

\```yaml
# 主配置文档
# 最后更新: 2026-05-12

# 数据库设置
database:
  # 数据库类型: sqlite 或 mysql
  type: sqlite
  
  # MySQL 配置 (仅当 type: mysql 时需要)
  mysql:
    host: localhost
    port: 3306
    database: rpg
    username: root
    password: ""
```

### 2.4 代码示例格式

所有代码示例必须使用语法高亮：

\```bash
# Bash 命令
java -Xms4G -Xmx4G -jar paper.jar
```

\```yaml
# YAML 配置
key: value
```

\```java
// Java 代码示例
public class Example {
}
```

### 2.5 提示框格式

使用自定义提示框来强调重要信息：

```markdown
::: tip 提示
这是一条提示信息
:::

::: warning 警告
这是一条警告信息
:::

::: danger 危险
这是一条危险信息
:::

::: info 信息
这是一条普通信息
:::
```

### 2.6 表格格式规范

表格必须包含表头，对齐方式要统一：

```markdown
| 列1 | 列2 | 列3 |
|------|------|------|
| 内容 | 内容 | 内容 |
```

推荐表格样式：
- 左对齐： `:------`
- 居中对齐： `:------:`
- 右对齐： `------:`

## 三、内容编写规范

### 3.1 语言风格

- 使用 **简体中文**
- 使用 **书面语**，避免口语化表达
- 使用 **第二人称**（你）或 **无主语**
- 技术术语保留英文原文，首次出现时附带中文解释

**好的示例：**
```markdown
配置数据库后，你需要重启服务器。
```

**不好的示例：**
```markdown
配置完数据库之后呢，你要重启一下服务器哦~
```

### 3.2 代码示例规范

- 代码示例必须 **可运行**
- 代码中的占位符使用 `<占位符>` 格式
- 代码示例必须包含注释说明

```markdown
\```bash
# 下载 Paper 服务端
wget <下载链接>

# 启动服务器
java -Xms4G -Xmx4G -jar <jar文件名>
```
```

### 3.3 图片使用规范

- 图片必须存储在 `assets/images/` 目录
- 图片文件名使用小写字母和连字符
- 图片必须添加 alt 文本

```markdown
![描述文字](assets/images/screenshot.png)
```

## 四、文档章节规范

### 4.1 标准章节顺序

每个插件文档应遵循以下章节顺序：

1. **简介** - 插件介绍、特点、前置要求
2. **安装** - 安装步骤、前置依赖
3. **快速开始** - 基础用法示例
4. **命令权限** - 命令列表和权限说明
5. **配置文件** - 配置项详细说明
6. **功能说明** - 详细功能介绍
7. **API 接口** - 开发者接口（如有）
8. **常见问题** - FAQ
9. **更新日志** - 版本更新记录

### 4.2 章节编号规则

- 一级章节使用中文数字：一、二、三...
- 二级章节使用阿拉伯数字：2.1、2.2、2.3...
- 三级章节使用阿拉伯数字：2.2.1、2.2.2...

## 五、特殊格式规范

### 5.1 必装/可选标记

使用徽章标记插件的必装或可选属性：

```markdown
| 插件 | 说明 | 必装 |
|------|------|------|
| RPGCore | 核心框架 | ✅ 是 |
| PlaceholderAPI | 变量支持 | ✅ 是 |
| Vault | 经济支持 | ❌ 否 |
```

### 5.2 版本标记

```markdown
- ✅ 支持
- ❌ 不支持
- ⚠️ 部分支持
- 🔄 测试中
```

### 5.3 链接格式

- 内部链接使用相对路径：`[链接文字](/path/to/page)`
- 外部链接必须添加 `target="_blank"` 标记（Docsify 会自动处理）

## 六、检查清单

在提交文档前，请确认：

- [ ] 所有标题都使用了正确的层级
- [ ] 所有代码块都使用了语法高亮
- [ ] 所有表格都正确格式化
- [ ] 所有链接都有效
- [ ] 代码示例经过测试
- [ ] 没有拼写错误
- [ ] 没有口语化表达
- [ ] 图片都有 alt 文本
- [ ] 文档末尾添加了更新日期

## 七、更新日志格式

每个文档末尾应包含更新日志：

```markdown
## 更新日志

### v1.0.0 (2026-05-12)
- 初始版本发布
- 添加基础功能文档

### v1.1.0 (2026-05-15)
- 添加 API 接口文档
- 修复命令说明错误
```
