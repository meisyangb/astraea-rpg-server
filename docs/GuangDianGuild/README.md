# GuangDianGuild

> 光点公会系统 — 创建/邀请/多级权限/公会聊天，基于 RPGCore GuildService 接口

---

## 一、简介

GuangDianGuild 提供完整的公会管理功能，支持公会创建、成员邀请、五级权限体系和公会专属聊天。

### 功能特性

- **五级权限** — 会长/副会长/长老/成员/新成员
- **邀请机制** — 60秒超时邀请
- **公会聊天** — `/g chat` 专属频道
- **自定义信息** — 公会前缀/描述

### 前置要求

| 插件 | 说明 | 必装 |
|------|------|:----:|
| RPGCore | 核心框架 | ✅ 是 |

---

## 二、命令权限

### 2.1 玩家命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/guild create <名称>` | `guangdian.guild.create` | 创建公会 |
| `/guild disband` | 无(需会长) | 解散公会 |
| `/guild invite <玩家>` | 无(需权限) | 邀请玩家 |
| `/guild accept` | 无 | 接受邀请 |
| `/guild kick <玩家>` | 无(需权限) | 踢出成员 |
| `/guild promote <玩家>` | 无(需会长) | 晋升成员 |
| `/guild info [公会名]` | 无 | 查看信息 |
| `/guild chat <消息>` | 无 | 公会聊天 |
| `/guild help` | 无 | 帮助 |

### 2.2 管理员命令

| 命令 | 权限 | 说明 |
|------|------|------|
| `/guildadmin reload` | `guangdian.guild.admin` | 重载配置 |
| `/guildadmin delete <公会名>` | `guangdian.guild.admin` | 强制删除公会 |

---

## 三、权限等级

| 等级 | 名称 | 优先级 |
|:----:|------|:----:|
| 5 | 会长 | 全部权限 |
| 4 | 副会长 | 管理成员 |
| 3 | 长老 | 邀请成员 |
| 2 | 成员 | 基础权限 |
| 1 | 新成员 | 无管理权限 |
