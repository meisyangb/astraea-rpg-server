# GuangDianBank

> 光点银行系统 — 存取款/利息结算/贷款/信用评分/交易历史

---

## 一、简介

GuangDianBank 提供完整的银行系统，支持存款取款、利息结算、贷款管理和信用评分。

### 功能特性

- **存取款** — 存入/取出现金
- **利息系统** — 定期结算存款利息
- **贷款管理** — 申请/还款/逾期检查
- **信用评分** — 根据还款记录动态调整
- **交易历史** — 所有操作完整记录

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/bank` | 无 | 打开银行界面 |
| `/bank balance` | 无 | 查看余额 |
| `/bank deposit <金额>` | 无 | 存款 |
| `/bank withdraw <金额>` | 无 | 取款 |
| `/bank loan` | 无 | 贷款管理 |
| `/bank help` | 无 | 帮助 |
