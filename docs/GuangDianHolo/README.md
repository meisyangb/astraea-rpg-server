# GuangDianHolo

> 光点全息显示 — Holographic Displays 集成，浮动文字/排行榜/属性面板

---

## 一、简介

GuangDianHolo 基于 Holographic Displays 提供全息浮动文字显示，支持排行榜、属性面板等动态内容。

---

## 二、命令权限

| 命令 | 权限 | 说明 |
|------|------|------|
| `/holo list` | 无 | 查看全息列表 |
| `/holo create <ID>` | `guangdian.holo.admin` | 创建全息 |
| `/holo delete <ID>` | `guangdian.holo.admin` | 删除全息 |
| `/holo reload` | `guangdian.holo.admin` | 重载配置 |
