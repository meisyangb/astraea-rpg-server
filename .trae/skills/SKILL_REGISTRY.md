## 技能组合策略

### 策略1: 单一技能模式
**适用场景**: 简单任务、明确需求
**示例**: "审查这段代码" → 仅激活 code-reviewer

### 策略2: 主从技能模式
**适用场景**: 需要领域知识 + 通用技能
**示例**: "优化GuangDianArmorStats性能" → minecraft-rpg-architect (主) + performance-tuner (从)

### 策略3: 多技能协作模式
**适用场景**: 复杂任务、涉及多个方面
**示例**: "开发一个新副本系统" → 
- minecraft-rpg-architect (架构设计)
- ui-designer (界面设计)
- code-reviewer (代码审查)
- documentation-writer (文档编写)

### 策略4: 全技能模式
**适用场景**: 系统级重构、大型项目
**示例**: "重构整个装备系统" → 激活所有相关技能

## 技能权重算法

### 权重计算公式
```
技能得分 = 关键词匹配度 × 0.4 + 任务类型匹配度 × 0.3 + 历史成功率 × 0.2 + 复杂度适配度 × 0.1
```

### 匹配度等级
| 等级 | 分值 | 说明 |
|------|------|------|
| 完全匹配 | 1.0 | 所有关键词都匹配 |
| 高度匹配 | 0.8 | 大部分关键词匹配 |
| 中度匹配 | 0.5 | 部分关键词匹配 |
| 低度匹配 | 0.2 | 少量关键词匹配 |
| 不匹配 | 0.0 | 无关键词匹配 |

用户: "如何创建一个新的菜单界面？"
