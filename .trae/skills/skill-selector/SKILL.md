# 技能选择器 (Skill Selector)

> 每次对话开始时自动调用，分析用户意图并选择最佳技能组合

---

## 工作流程

```
用户输入 → 意图分析 → 技能评估 → 技能选择 → 激活执行
```

---

## 意图分析维度

### 1. 技术领域识别
| 关键词 | 可能领域 | 推荐技能 |
|--------|----------|----------|
| 插件、RPG、Minecraft、Paper | 游戏开发 | minecraft-rpg-architect |
| 数据库、SQL、MySQL、Redis | 数据存储 | database-optimizer |
| 性能、优化、卡顿、内存 | 性能优化 | performance-tuner |
| UI、界面、菜单、GUI | 界面开发 | ui-designer |
| 配置、YAML、JSON、文件 | 配置管理 | config-manager |
| 网络、协议、数据包 | 网络开发 | network-engineer |
| 安全、权限、漏洞 | 安全开发 | security-auditor |
| 测试、JUnit、Mock | 测试开发 | test-engineer |

### 2. 任务类型识别
| 任务类型 | 特征 | 处理方式 |
|----------|------|----------|
| **开发新功能** | "创建"、"添加"、"实现" | 激活开发技能 + 代码审查技能 |
| **修复问题** | "修复"、"解决"、"Bug" | 激活调试技能 + 对应领域技能 |
| **优化改进** | "优化"、"改进"、"提升" | 激活优化技能 + 性能分析技能 |
| **代码审查** | "审查"、"检查"、"规范" | 激活审查技能 + 规范检查技能 |
| **学习咨询** | "如何"、"为什么"、"解释" | 激活教学技能 + 文档查询 |
| **架构设计** | "设计"、"架构"、"结构" | 激活架构师技能 + 设计模式技能 |

### 3. 复杂度评估
| 复杂度 | 指标 | 技能数量 |
|--------|------|----------|
| 简单 | 单文件修改、配置调整 | 1-2 个技能 |
| 中等 | 多文件协调、功能实现 | 2-3 个技能 |
| 复杂 | 系统级改动、架构重构 | 3-5 个技能 |

## 可用技能清单

### 核心技能
| 技能ID | 名称 | 专长领域 | 触发条件 |
|--------|------|----------|----------|
| `minecraft-rpg-architect` | RPG架构师 | Minecraft RPG插件开发 | 涉及GuangDian*插件、RPGCore |
| `code-reviewer` | 代码审查员 | 代码质量、规范检查 | 代码审查、规范验证 |
| `performance-tuner` | 性能优化师 | JVM调优、性能分析 | 性能问题、优化需求 |
| `database-optimizer` | 数据库优化师 | SQL优化、缓存设计 | 数据库相关 |
| `ui-designer` | UI设计师 | 界面设计、用户体验 | GUI、菜单、显示系统 |
| `config-manager` | 配置管理师 | YAML/JSON配置 | 配置文件相关 |
| `security-auditor` | 安全审计员 | 安全漏洞、权限控制 | 安全相关 |
| `test-engineer` | 测试工程师 | 单元测试、集成测试 | 测试相关 |
| `git-master` | Git专家 | 版本控制、分支管理 | Git操作、代码合并 |
| `documentation-writer` | 文档撰写员 | 技术文档、注释规范 | 文档相关 |

## 技能组合推荐

### 场景1: 开发新插件
**推荐技能组合:**
1. `minecraft-rpg-architect` - 主开发技能
2. `code-reviewer` - 代码审查
3. `documentation-writer` - 文档编写

### 场景2: 修复性能问题
**推荐技能组合:**
1. `performance-tuner` - 性能分析
2. `minecraft-rpg-architect` - 领域知识
3. `database-optimizer` - 数据库优化（如涉及）

### 场景3: 重构代码
**推荐技能组合:**
1. `minecraft-rpg-architect` - 架构指导
2. `code-reviewer` - 规范检查
3. `test-engineer` - 测试保障
4. `git-master` - 版本管理

### 场景4: 添加新功能
**推荐技能组合:**
1. `minecraft-rpg-architect` - 功能实现
2. `ui-designer` - 界面设计（如涉及）
3. `config-manager` - 配置设计
4. `code-reviewer` - 代码审查

### 场景5: 安全修复
**推荐技能组合:**
1. `security-auditor` - 安全分析
2. `minecraft-rpg-architect` - 修复实现
3. `test-engineer` - 安全测试

## 使用方式

### 自动模式（推荐）
每次对话开始时，系统自动：
1. 分析用户输入
2. 评估所需技能
3. 激活最佳技能组合
4. 展示技能选择理由

### 手动模式
用户可显式指定：
```
使用 [技能名] 技能来...
激活 [技能1] 和 [技能2] 处理...
```
