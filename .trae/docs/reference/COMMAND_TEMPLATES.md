## 开发任务

### 创建新插件
```
帮我创建一个新的插件 [插件名称]，功能需求如下：
1. [功能1描述]
2. [功能2描述]
3. [功能3描述]

要求：
- 继承 AbstractRPGPlugin
- 使用 [需要的RPGCore服务]
- 需要的数据结构：[数据描述]
```

**示例**：
```
帮我创建一个新的插件 GuangDianAuction，功能需求如下：
1. 玩家可以发布物品拍卖
2. 其他玩家可以出价竞拍
3. 拍卖结束时自动交易

要求：
- 继承 AbstractRPGPlugin
- 使用 RPGCore 的 ServiceRegistry、PlayerLockManager
- 需要的数据结构：拍卖物品、出价记录、拍卖状态
```

## 💡 使用技巧

### 1. 提供上下文
始终在指令中提供足够的上下文信息：
- ✅ "在 GuangDianPoints 的 PointsServiceImpl.java 中..."
- ❌ "在这个文件中..."

### 2. 明确期望
清楚说明你想要的结果：
- ✅ "请提供三种实现方案，并分析各自的优缺点"
- ❌ "帮我看看怎么写"

### 3. 分步骤进行
复杂任务分步骤进行：
```
第一步：分析需求
第二步：设计方案
第三步：实现代码
第四步：测试验证
```

### 4. 使用检查清单
使用检查清单确保完整性：
```
请检查：
- [ ] 是否符合禁止模式
- [ ] 是否有异常处理
- [ ] 是否更新文档
```
